# 《装机人生》发布页文案

## 基本信息

- 名称：装机人生
- 英文名：PC Building Life
- 当前版本：0.1.0-dev
- 平台：Windows x86_64
- 版本定位：试玩候选版
- 当前建议渠道：封闭测试下载页 / itch.io 草稿页 / 私域试玩群

## 一句话介绍

从接单、采购、装机到开机跑分，体验一台电脑交付给客户前的完整装机流程。

## 简介

《装机人生》是一款电脑装机模拟经营游戏。玩家扮演刚起步的装机工，接取客户订单，根据预算和性能需求采购 CPU、主板、显卡、内存、硬盘、电源、机箱等配件，在工作台完成安装、兼容性检查、开机验证、驱动配置、跑分和稳定性测试，最后交付订单并获得评分与收益。

当前版本已经形成核心闭环：订单、商店、仓库、拖动安装、开机、模拟系统、软件配置评分、交付回执、存档读取和 12 单首发订单流程。长期经营、职业路线、随机事件、品牌合作和更深入的模拟 OS 玩法会在后续版本继续扩展。

## 主要卖点

- 订单驱动的装机经营循环：先看客户需求，再按预算和评分目标选择配件。
- 商店和仓库全屏目录：减少来回切换，支持购买、购买并安装、库存安装和出售。
- 可视化工作台：安装槽位、完成度、兼容性、开机状态和下一步提示集中展示。
- 模拟 OS 玩法雏形：Driver Tool、System Info、Benchmark、Stability Test 会影响交付评分。
- 软件配置完成度接入订单评分：不是只拼硬件，开机后的操作也会影响收益。
- 新手引导和自动化验证：首次游玩可按引导完成第一单，发布包已通过 12 单玩家流和首单审计。

## 下载说明

1. 下载 `PCBuildingLife-Windows-x64-0.1.0-dev.zip`。
2. 解压到本地目录。
3. 双击 `PCBuildingLife.exe` 启动。
4. 第一次游玩建议点击“新游戏”，跟随底部流程完成第一单。
5. 如果 Windows 弹出安全提示，请确认文件来自项目发布包后再允许运行。

## 已知限制

- 当前仍是开发候选版，内容量以首发订单池和核心闭环为主。
- 暂未接入 Steam/itch SDK、云存档、成就、崩溃上报或自动更新。
- 当前运行时配件图、PC 预览、应用图标、正式封面和渠道头图已替换为自有程序化素材。
- 统一反馈入口已准备：GitHub Issues。
