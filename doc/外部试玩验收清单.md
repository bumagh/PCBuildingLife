# 《装机人生》外部试玩验收清单

## 试玩目标

本清单用于 0.1.0-dev 第一批外部试玩。目标不是评价最终商业品质，而是确认一个真实玩家能在普通 Windows 环境中完成核心闭环：

1. 下载并解压游戏。
2. 启动 `PCBuildingLife.exe`。
3. 新游戏完成第一单 `社区办公机`。
4. 保存并重启后继续游戏。
5. 提交可复现的反馈。

## 启动步骤

1. 解压 `PCBuildingLife-Windows-x64-0.1.0-dev-playtest-kit.zip`。
2. 双击 `START_PLAYTEST_KIT.cmd`，它会先校验 `package/PCBuildingLife-Windows-x64-0.1.0-dev.zip.sha256` 再启动，并且应该直接显示游戏窗口。
3. 第一次进入选择“新游戏”。
4. 跟随新手引导完成第一单。
5. 游戏关闭后查看自动生成的 `PLAYTEST_SESSION_*.md` 和 `PLAYTEST_REPORT_*.md`，直接在报告副本里回填结果；报告中的游戏版本和 Package SHA-256 用于确认这份反馈对应当前候选包。
6. 如果游戏崩溃、黑屏、无法继续或问题难以复现，双击 `COLLECT_SUPPORT_BUNDLE.cmd`，把生成的 `PCBuildingLife-support-*.zip` 一起提交。

如果 Windows SmartScreen 或杀毒软件提示，请记录截图和提示内容，不要直接忽略。

## 首单验收路径

需要完成：

- 接取第一单 `社区办公机`。
- 购买缺失配件。
- 使用“购买并安装”或拖拽安装完成硬件。
- 执行硬件检查。
- 点击电源按钮开机。
- 打开模拟 OS。
- 完成 Driver Tool、Benchmark 或当前订单要求的软件配置。
- 交付订单并看到评分回执。
- 保存游戏。
- 关闭后重新启动，确认可以继续游戏。

通过标准：

- 游戏没有崩溃。
- 第一单可以完成。
- 交付后能看到奖励、评分和反馈。
- 保存后能继续。
- 主要按钮没有遮挡、重叠或点不到。

## 30 分钟试玩观察

首单完成后，建议继续玩 30 分钟并记录：

- 哪一步最困惑？
- 商店、仓库、订单大厅、任务中心是否容易理解？
- 模拟 OS 是否能看出它影响交付评分？
- 哪些配件图标或名称看不懂？
- 哪个界面太窄、太挤或不够像游戏？
- 是否有明显卡顿、黑屏、无响应或异常退出？
