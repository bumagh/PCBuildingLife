# 装机人生策划案（整理版）

## 1. 项目概述

《装机人生》是一款以电脑装机、系统配置、订单交付和经营扩张为主线的模拟经营游戏。玩家从低预算起步，通过接单、采购、装机、开机、驱动与软件配置、跑分和交付，不断把小工作室做大。

核心体验不是单纯“买零件”，而是让配件选择、兼容性、预算控制和系统配置共同构成策略。

## 2. 产品定位

- 平台优先级：PC / Windows 首发
- 参考方向：Steam 上的装机模拟器、视频平台的装机内容、PC Creator 2 的视觉和交互结构
- 商业模式：先买断，后续可扩展广告合作、品牌合作或增值内容

## 3. 核心循环

1. 查看订单和需求
2. 进入商店挑选配件
3. 背包整理、拖拽安装、兼容性检查
4. 开机检测、安装驱动、配置软件、跑分和稳定性测试
5. 交付结算、获得评分和奖励
6. 用收益扩充库存、能力和订单池

## 4. 玩家身份与成长

玩家可从不同职业切入：

- 游戏开发程序员
- 美术设计
- 游戏策划
- 游戏玩家
- 装机工

基础属性建议保留三条主线：

- 上班勤奋值：影响工作收益
- 省钱值：影响采购折扣
- 人脉值：影响客户和机会

初始资金建议保持低门槛起步，例如 100 元，让前期“攒第一台电脑”的目标更明确。

## 5. 订单与事件

订单类型可以分成几类：

- 办公机
- 游戏机
- 设计机
- 主播机
- 比赛单
- 稳定性单
- 软件配置单

事件则负责制造阶段性压力和升级动力：

- 系统更新
- 新软件发布
- CPU / GPU 带不动
- 客户追加需求
- 保修与返修

比赛可以继续保留：

- 装机大赛
- 最低预算
- 最佳性能
- 最短用时
- 自媒体大赛

## 6. 系统与界面

界面目标是“工作台 + 电脑 + 全屏工作区”，而不是一堆窄 tab。

建议保留的主要界面：

- 工作台
- 电脑
- 日历
- 邮箱
- 商城
- 文件
- 工具
- 货物柜
- 垃圾桶
- 手机 / 平板

电脑内可继续承载：

- CPU-Z
- GPU-Z
- softcenter
- canrun

UI 结构上，首页底部、订单、系统这些入口应优先做成：

- 底部工作区
- 全屏 overlay
- 弹窗 / 快捷入口

这样能减少频繁切 tab，并让玩家更快进入操作。

## 7. 美术与素材

视觉方向建议继续参考 PC Creator 2 的深蓝紫、卡片化、手游工作台风格，但落地时要做成自己的版式，而不是照搬。

素材策略建议：

- 先用竞品素材建立结构参照
- 明确每张图的来源、用途和替换关系
- 优先建立配件图与 UI 图的映射表
- 后续把硬编码资源逐步迁到数据配置

## 8. 内容节奏

- 前 10 分钟：接单、购买、安装、开机、交付
- 前 60 分钟：驱动、软件配置、跑分、稳定性测试
- 中期：更多订单类型、更复杂兼容、更高预算
- 后期：模拟 OS 深化、系统任务、竞赛和长期经营

## 9. 现状核对

当前主线工程已经迁到 `GodotVersion/`，并且已经具备以下可玩内容：

- 购买、背包、安装、兼容性检查、订单、评分、存档和新手引导
- `HomeBottomDock`、`WorkbenchFooter`、Task Center、Order Desk、Catalog overlay
- 模拟 OS、交付回执、关键动画、金手指测试按钮
- 截图检查和 MCP smoke 验证流程

当前还需要继续补强的方向：

- 统一首页、工作台、商店、背包、订单和模拟 OS 的视觉语言
- 把模拟 OS 的软件配置完成度真正接入订单评分和交付结果
- 整理竞品素材与配件图的管线
- 清理发布包中的开发工具、测试入口和未使用资源

## 10. 备注

本策划案不是静态概念稿，而是要跟当前 GodotVersion 的真实实现同步更新。后续如果玩法和界面发生较大变化，应优先把本文和排期文档一起改掉。
