1. 下载 `PCBuildingLife-Windows-x64-0.1.0-dev.zip`。
2. 解压到本地目录。
3. 双击 `PCBuildingLife.exe` 启动。
4. 第一次游玩建议选择“新游戏”，跟随新手引导完成第一单。

校验：

下载后可对照同目录的 `.sha256` 文件确认 ZIP 没有损坏。

已知限制：

当前版本是试玩候选包，首发内容以订单池和核心装机闭环为主。长期经营、职业路线、事件系统和更深入的模拟 OS 玩法仍在后续版本开发中。
