## 上线判定

公开前至少满足：

- 3 名以上外部测试者能启动游戏。
- 3 名以上外部测试者能完成第一单、保存、重启并继续。
- 3 份有效报告的 Package SHA-256 必须匹配当前玩家 ZIP SHA-256；旧包或缺失哈希的报告只作为参考，不计入 go 判定。
- 没有 P0 阻塞问题。
- P1 严重问题有明确修复计划或规避说明。
- 下载包 SHA、反馈入口、隐私说明和已知限制都与当前发布页一致。

机器汇总命令：

```powershell
& .\GodotVersion\scripts\summarize_playtest_reports.ps1
& .\GodotVersion\scripts\verify_release_readiness.ps1
```

`summarize_playtest_reports.ps1` 会输出 `GodotVersion/build/playtest/feedback-summary/playtest-feedback-summary-0.1.0-dev.{json,md}`；`verify_release_readiness.ps1` 会读取该汇总，并在外部报告不足、旧包报告、P1/P0 或 no-go 时给出 warn/fail。

## 问题分级

P0 阻塞：

- 无法启动。
- 首单无法完成。
- 无法保存或继续。
- 交付、开机、购买、安装任一核心闭环必现卡死。
- 公开包包含调试入口、敏感文件或非授权素材。

P1 严重：

- 关键 UI 被遮挡、点不到或文字严重溢出。
- 新手引导误导玩家，导致多数测试者卡住。
- 模拟 OS 操作无法理解其对订单评分的影响。
- 性能、黑屏、无响应或杀毒拦截导致多人中断。

P2 普通：

- 文案不清楚但可继续。
- 单个配件图标或状态说明难懂。
- 非核心界面拥挤、风格不统一。
- 建议增加快捷入口、音效、动画或提示。
