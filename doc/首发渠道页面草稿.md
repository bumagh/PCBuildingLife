# 《装机人生》首发渠道页面草稿

版本：0.1.0-dev

## 推荐首发方式

当前首发方式改为 GitHub 源码仓库，暂不使用 itch.io 或其他下载渠道。理由是当前版本已经具备可玩核心闭环，但长期经营、职业路线、事件系统、竞赛玩法和更深入的模拟 OS 仍在开发中；先公开源码和统一 README，便于玩家和开发者按同一流程运行、构建和反馈。

推荐优先级：

1. GitHub 仓库：提供 GodotVersion 主工程、README、策划案、测试脚本和反馈入口。
2. GitHub Issues：收集启动、UI、装机流程和模拟 OS 的问题。
3. 本地构建：玩家按 README 运行 `build_release.ps1` 生成 Windows x86_64 包。

## 一句话介绍

从接单、采购、装机到开机跑分，体验一台电脑交付给客户前的完整装机流程。

## 短简介

《装机人生》是一款电脑装机模拟经营游戏。你将接取客户订单，根据预算和性能需求采购 CPU、主板、显卡、内存、硬盘、电源、机箱等配件，在工作台完成安装、兼容性检查、开机验证、驱动配置、跑分和稳定性测试，最后交付订单并获得评分与收益。

## 长简介

当前试玩候选版已经形成核心可玩闭环：订单、配件市场、仓库、拖拽安装、兼容性检查、开机、模拟 OS、软件配置评分、交付回执、保存读取和 12 单首发订单流程。

游戏的重点不是单纯“买最贵配件”，而是在客户预算、硬件兼容、性能要求和软件配置之间做取舍。开机后的 Driver Tool、GPU 驱动、Benchmark 和 Stability Test 会影响交付评分，让装机订单不仅看硬件，还看交付前的软件准备。

长期经营、职业路线、随机事件、比赛系统、更多配件品牌和更深入的模拟 OS 玩法会在后续版本继续扩展。

## 核心卖点

- 订单驱动的装机经营循环：看客户需求，按预算和评分目标采购配件。
- 全屏配件市场和仓库：支持购买、购买并安装、库存安装、出售和筛选。
- 可视化工作台：核心槽位、完成度、兼容性、开机状态和下一步提示集中展示。
- 模拟 OS 玩法雏形：Driver Tool、System Info、Benchmark、Stability Test 会影响交付评分。
- 软件配置完成度接入订单结果：不是只拼硬件，开机后的操作也会影响收益。
- 新手引导和自动化验证：首次游玩可按引导完成第一单，当前发布包已通过 12 单玩家流、首单审计和模拟下载包验收。

## 系统要求

最低建议：

- Windows 10 / Windows 11 64 位
- 1280x720 或更高分辨率
- 支持 Vulkan 的显卡或集成显卡
- 至少 4 GB 可用内存

## 当前版本内容

- 12 个首发订单，包含不同客户类型、难度、奖励和软件任务。
- 配件市场、仓库、购买并安装、拖拽安装、出售和筛选。
- 工作台可视化插槽、装机检查、兼容性检查和电源按钮。
- 模拟 OS：系统信息、Driver Tool、GPU 驱动、Benchmark、稳定性测试、文件页和关机。
- 任务中心、订单大厅、系统中心、目录覆盖层和交付回执。
- 保存/读取、坏档恢复、设置菜单、主菜单和新手引导。
- 自有程序化配件图标、详情图、PC 预览、应用图标、封面和渠道头图。

## 已知限制

- 当前版本是试玩候选包，不是最终商业发行版。
- 内容量以首发订单池和核心装机闭环为主。
- 长期经营、职业路线、随机事件、比赛玩法和更深入的模拟 OS 仍在开发中。
- 暂未接入 Steam/itch SDK、云存档、成就、崩溃上报或自动更新。
- 当前仅提供 Windows Desktop 包。

## 隐私与反馈

当前 Windows 试玩候选版是本地单机游戏，不需要注册账号，不需要联网登录，不接入广告 SDK、支付 SDK、统计 SDK、云存档或崩溃上报服务。
