# PCBuildingLife 干净机器首单验收清单

## 目的

用于真实公开下载或另一台干净 Windows 机器上的上线前首单验收。该流程验证玩家不依赖开发环境、旧存档或本机 Godot 工具，也能下载/解压、启动游戏、完成第一单、保存并继续。

## 生成验收包

```powershell
& .\GodotVersion\scripts\prepare_clean_machine_validation_kit.ps1
& .\GodotVersion\scripts\verify_clean_machine_validation_kit.ps1
```

输出：

- `GodotVersion/build/clean-machine-validation/PCBuildingLife-0.1.0-dev/`
- `GodotVersion/build/clean-machine-validation/PCBuildingLife-0.1.0-dev-clean-machine-validation-kit.zip`
- `GodotVersion/build/clean-machine-validation/clean-machine-validation-kit-audit-0.1.0-dev.json`

## 在另一台 Windows 上执行

1. 解压 `PCBuildingLife-0.1.0-dev-clean-machine-validation-kit.zip`。
2. 双击 `RUN_CLEAN_MACHINE_VALIDATION.cmd`。
3. 等脚本完成 SHA-256 校验并启动 `PCBuildingLife.exe`。
4. 新游戏完成第一单。
5. 保存，关闭，再确认继续游戏能读取存档。
6. 填写生成的 `CLEAN_MACHINE_REPORT_*.md`。
7. 回收生成的 `CLEAN_MACHINE_REPORT_*.md` 和 `CLEAN_MACHINE_SESSION_*/clean-machine-session-*.json`。

## 回收报告

将回收文件放入：

- `GodotVersion/build/clean-machine-validation/incoming-reports/`

然后运行：

```powershell
& .\GodotVersion\scripts\receive_clean_machine_reports.ps1
& .\GodotVersion\scripts\verify_release_readiness.ps1
```

导入脚本会输出：

- `GodotVersion/build/clean-machine-validation/report-intake/clean-machine-report-intake-0.1.0-dev.json`
- `GodotVersion/build/clean-machine-validation/report-intake/clean-machine-report-intake-0.1.0-dev.md`

## 通过条件

- 当前玩家 ZIP SHA-256 匹配候选包。
- 游戏窗口可见启动。
- 首单可完成并得到交付评分。
- 保存后能继续游戏。
- 测试报告中的 Package SHA-256 等于当前候选包。
- `receive_clean_machine_reports.ps1` 对当前候选包输出 `decision=go`。
- 没有 P0 阻塞、崩溃、黑屏、无法点击、无法保存或无法继续。
