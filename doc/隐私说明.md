# 《装机人生》隐私说明

版本：0.1.0-dev

## 当前数据处理范围

当前 Windows 试玩候选版是本地单机游戏，不需要注册账号，不需要联网登录，不接入广告 SDK、支付 SDK、统计 SDK、云存档或崩溃上报服务。

游戏会在本机用户数据目录写入以下本地文件：

- 游戏存档：资金、背包、已安装配件、订单进度、软件任务状态。
- 设置文件：音量、窗口模式、分辨率等本地偏好。
- 坏档恢复文件：当存档损坏时，游戏可能保留上一版备份或归档坏档，便于恢复。

## 不收集的内容

当前版本不会主动收集、上传或共享以下内容：

- 玩家姓名、手机号、邮箱、身份证件或支付信息。
- 本机文件列表、浏览记录、联系人或地理位置。
- 游戏外截图、键盘输入记录或麦克风/摄像头数据。
- 远程诊断日志、崩溃报告或硬件标识。

## 玩家可控内容

玩家可以删除本地存档和设置文件来重置游戏进度。后续如果接入云存档、排行榜、崩溃反馈或数据统计，需要在发布前更新本说明，并在游戏内或发布页明确告知。

## 联系与反馈

当前版本的统一反馈入口为 GitHub Issues：

https://github.com/bumagh/PCBuildingLife/issues

玩家主动提交反馈时，Issue 内容会由 GitHub 托管，并可能包含玩家自行提供的系统版本、截图、录屏、复现步骤或其他说明。请不要在反馈中提交手机号、身份证件、支付信息、账号密码或其他敏感个人信息。
