# Competitor Reference Pointer

This directory intentionally contains no competitor images or Godot import metadata.

Use the repository-level `ReferenceAssets/PC_Creator2/` directory for visual and
interaction research. The previous Godot-project copy is preserved at
`ReferenceAssets/PC_Creator2/legacy_godot_project_copy/` for audit purposes.

Public runtime assets must continue to come from `assets/original/` or another
documented, commercially usable source.
