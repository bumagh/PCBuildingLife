PC Building Life 0.1.0-dev
==========================

这是《装机人生》的 Windows 试玩候选版。当前版本已经包含接单、购买配件、背包、安装、兼容性检查、开机、模拟 OS、驱动、跑分、稳定性测试、交付评分、保存和读取流程。

启动方法
--------
1. 解压整个 ZIP 到一个普通英文或中文目录。
2. 双击 PCBuildingLife.exe。
3. 第一次游玩请选择“新游戏”。

基础流程
--------
1. 在首页查看当前订单，或打开“任务中心”。
2. 按订单要求去“配件市场”购买配件。
3. 可以直接“购买并安装”，也可以进入“仓库”后拖拽安装。
4. 工作台完成核心配件后点击“完成检测”。
5. 点击“电源按钮”，进入模拟系统。
6. 在“系统中心”或 Max Monitor 中完成 Driver Tool、Benchmark、稳定性测试等软件任务。
7. 回到任务中心或订单区交付订单，查看评分和奖励。
8. 游戏会保存资金、库存、已安装配件、订单进度和系统配置状态。

建议配置
--------
- Windows 10 / Windows 11 64 位
- 1280x720 或更高分辨率
- 独立显卡或支持 Vulkan 的集成显卡
- 至少 4 GB 可用内存

常见问题
--------
- 如果 Windows 弹出安全提示，请确认文件来自项目发布包后再允许运行。
- 如果无法启动，请尝试换到不含特殊符号的路径重新解压。
- 如果画面比例异常，请进入暂停菜单调整窗口分辨率或全屏设置。
- 如果存档异常，主菜单会提示恢复或重新开始。
- 如果需要反馈崩溃、黑屏或无法继续的问题，可以双击随包的 COLLECT_SUPPORT_BUNDLE.cmd，生成支持 ZIP 后一并提交。

当前版本定位
------------
这是公开试玩候选版，不是最终商业发行版。内容量以首发订单池和核心装机循环为主，后续版本会继续扩展职业、事件、更多订单和更深入的模拟 OS 玩法。
